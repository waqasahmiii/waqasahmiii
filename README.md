<summary><b>🐛 Bugs that taught me more than any tutorial</b> (click to expand)</summary>
<br>

- Spent an hour confused why three cards were animating on hover when I'd only touched one — turns out I'd attached `:hover` to the wrong parent
- Learned the hard way that CSS Grid treats *any* direct child as a grid item — including a heading I forgot to move outside the container
- Found out a sticky navbar and anchor-link scrolling don't get along by default, until `scroll-padding-top` fixed it in one line
